# Credits & Asset Licences

The shipped project uses **only procedurally generated geometry** — no third-party
assets are bundled, so nothing here needs crediting yet.

This file is the single source of truth for asset licensing. **Any model added to
`Content/` gets a row here in the same commit.**

## How to use this

When you import your Sketchfab models, most are **CC-BY 4.0**, which *requires*
attribution wherever you publish the game. Paste the relevant lines into an in-game
credits screen or your store page, in the format Sketchfab recommends:

> "MODEL NAME" by AUTHOR, licensed under CC BY 4.0 — <model URL>

The **Verified** column means someone loaded the model's page and read the licence line
with their own eyes. Never promote a row to ✅ on the strength of a search result or a
recollection — an unverified row is a known unknown, which is safe; a wrongly verified
row is a licence violation waiting to happen.

## Rows that need your attention before shipping

- **Low Poly Mine** — the licence was read, but the model ID on the page found does not
  match the link on file. Confirm you have the right model before relying on that
  licence; two different models can share a name.
- **Low poly Tree pack**, **Low Poly Grass Asset Pack** — the licence line could not be
  checked. Open each page and read it yourself. Until then, treat both as
  "all rights reserved" and do not publish with them.

## Also watch for

A **"NoAI"** tag on a model's page does not stop you using the model in a game, but it
signals the author is strict about terms — read them in full before using it.
